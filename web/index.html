Lish

The terminal connects to a full RISC-V Linux machine. The emulator and its JIT run in a dedicated Web Worker.

Run it locally

brew install coreutils genext2fs zig
npm ci && npm run stage-web-dependencies
web/prepare-images.sh
tools/cargo build -p rv64-wasm --target wasm32-unknown-unknown --release
python3 -m http.server 4173
# open http://127.0.0.1:4173/web/

The page loads local build artifacts from the same origin. Run the native network host to enable guest networking.
